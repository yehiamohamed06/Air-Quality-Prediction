# 🌤️ Air Quality Prediction using Machine Learning

## 📌 Project Overview
This project predicts the Air Quality Index (AQI) and pollutant levels (PM2.5, PM10, Ozone, NO2, CO, SO2) based on environmental and meteorological indicators using Machine Learning.

## 🛠️ Tech Stack & Libraries
- **Language:** Python
- **Data Analysis & Viz:** Pandas, NumPy, Matplotlib, Seaborn
- **Machine Learning:** Scikit-Learn

## 📊 Dataset Features
- **Date & City:** Location and timeline indicators.
- **Pollutants:** PM2.5, PM10, Ozone, NO2, CO, SO2.
- **Weather Metrics:** Temperature, Humidity.
- **Target:** Air Quality Index (AQI).

## 🚀 Workflow
1. **Data Preprocessing & Cleaning:** Handling missing values, feature types, and scaling.
2. **Exploratory Data Analysis (EDA):** Analyzing feature distributions and correlations.
3. **Model Building & Evaluation:** Training ML models and assessing performance with metrics like R² and RMSE.
